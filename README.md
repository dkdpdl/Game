# 늑대섬 탐험기 (프로토타입)

도트 그래픽 무인도 탐험 모바일 웹게임입니다.
표류한 섬에서 자원을 모아 도구를 만들고, 늑대를 동료로 삼아 고대 유적의 수수께끼를 풉니다.

## 실행 방법

외부 라이브러리 없이 순수 HTML/JavaScript로 만들어서, 빌드 과정이 필요 없습니다.

- **PC**: `index.html`을 브라우저로 열면 바로 실행됩니다.
- **로컬 서버** (휴대폰으로 같은 와이파이에서 접속할 때): `npm start` 후 `http://<PC의 IP>:8080` 접속
- **GitHub Pages**: 저장소 Settings → Pages에서 이 브랜치를 선택하면 휴대폰 브라우저에서 링크로 플레이할 수 있습니다.

## 조작

| 동작 | 모바일 | PC |
|---|---|---|
| 이동 | 가고 싶은 곳 터치 | 방향키 / WASD |
| 채집·조사·대화 | 대상 터치 (자동으로 다가감) | 스페이스 / 엔터 (바라보는 방향) |
| 가방 / 제작 | 오른쪽 아래 버튼 | I / C |
| 늑대 킁킁 | 킁킁 버튼 | F |

## 게임 내용 (챕터 1)

1. **생존**: 나뭇가지·돌·풀줄기를 모아 돌도끼 → 통나무를 얻어 모닥불
2. **늑대**: 북서쪽 숲의 다친 늑대에게 구운 고기(멧돼지 사냥 → 모닥불 요리)를 주면 동료가 됨
3. **수수께끼 3종**
   - 유적 문 비석: 선택형 수수께끼
   - 유적 안 석상 4개: 벽 글귀를 보고 순서대로 만지기
   - 난파선 비석: 수수께끼의 답이 되는 **아이템을 만들어 바치기**
4. **늑대 능력 퍼즐**: 달의 조각은 땅에 묻혀 있어서 늑대의 `킁킁`으로만 찾을 수 있음
5. 해·달·별 조각 3개를 제단에 바치면 챕터 1 클리어

### 늑대(펫) 시스템
- 먹이를 주면 친밀도 상승 → 레벨업
- Lv1 `킁킁`: 주변에 묻힌 보물 탐지 (레벨이 오르면 범위 증가)
- Lv2 `사냥 도움`: 멧돼지 공격 시 피해 +1
- Lv3 `채집 도움`: 채집 시 30% 확률로 하나 더

### 기타
- 레벨/경험치, 스태미나(행동 시 소모, 음식으로 회복, 천천히 자연 회복)
- 자원은 시간이 지나면 다시 생김
- 낚시 (낚싯대 제작 후 물 터치)
- 자동 저장 (브라우저 localStorage, 10초마다)
- 효과음은 파일 없이 코드로 합성 (메뉴에서 끄기 가능)

## 파일 구조

```
index.html        화면 구성
css/style.css     UI 스타일
js/sprites.js     도트 그림 (문자열 → 픽셀)
js/data.js        아이템·제작법·요리법
js/world.js       섬 지도 생성, 바닥 타일 그리기
js/game.js        게임 로직 (이동, 채집, 늑대, 멧돼지, 수수께끼, 그리기)
js/ui.js          HUD, 가방·제작·늑대 창, 대화창, 효과음
js/main.js        시작 화면, 입력, 게임 루프
tools/smoke.mjs   자동 테스트 (실제 브라우저로 전체 흐름 확인)
```

## 테스트

```
npm install
npm test
```

모바일 화면 크기로 게임을 열어, 주요 장소에 모두 갈 수 있는지와
채집 → 제작 → 늑대 길들이기 → 수수께끼 3종 → 클리어 → 저장/불러오기까지 자동으로 확인합니다.
스크린샷은 `tools/out/`에 저장됩니다.

## 앞으로 할 수 있는 것
- 전문 도트 작가의 그래픽으로 교체 (스프라이트는 `js/sprites.js`에 모여 있음)
- 새 지역·챕터, 펫 종류 추가, 배경 음악
- Capacitor로 감싸 iOS/Android 앱으로 출시
